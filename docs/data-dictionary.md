# Data Dictionary

## Survey Fields

| Field | Type | Description |
|---|---|---|
| Unique ID | Text | Survey response identifier |
| Email | Text | Respondent email (mostly anonymous) |
| Date Taken | Date | Date of response |
| Time Taken | Time | Time of response |
| Browser | Text | Browser used |
| OS | Text | Operating system |
| City | Text | City |
| Country | Text | Country |
| Referrer | Text | Traffic source |
| Time Spent | Time | Time spent on survey |
| Q1 - Current Role | Text | Job title |
| Q2 - Career Switch | Text | Yes / No |
| Q3 - Salary | Text | Salary range in USD |
| Q4 - Industry | Text | Industry |
| Q5 - Favorite Programming Language | Text | Preferred language |
| Q6 - Happiness (Salary) | Integer | 0–10 rating |
| Q6 - Happiness (Work/Life Balance) | Integer | 0–10 rating |
| Q6 - Happiness (Coworkers) | Integer | 0–10 rating |
| Q6 - Happiness (Management) | Integer | 0–10 rating |
| Q6 - Happiness (Upward Mobility) | Integer | 0–10 rating |
| Q6 - Happiness (Learning New Things) | Integer | 0–10 rating |
| Q7 - Difficulty to Break Into Data | Text | Very Easy to Very Difficult |
| Q8 - Most Important Job Factor | Text | Remote Work, Better Salary, etc. |
| Q9 - Gender | Text | Male / Female |
| Q10 - Age | Integer | Respondent age |
| Q11 - Country | Text | Country of residence |
| Q12 - Education | Text | Highest education level |
| Q13 - Ethnicity | Text | Self-reported ethnicity |

## Notes
- Salary is recorded as a range, not an exact value.
- Some free-text fields have inconsistent formatting.
- Country field includes "Other (Please Specify)" entries.
